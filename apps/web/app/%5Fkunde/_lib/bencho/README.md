# Bencho dock

MIT. Kilde: [cabralorenzo/bencho `blocks/dock`](https://github.com/cabralorenzo/bencho/tree/main/blocks/dock). Live: https://bencho.dev/blocks/dock (`?c=dock&theme=light`).

`GlassDock.tsx` er Bencho-strukturen (`items` / `active` / `onSelect`, `.gdock` + prikk) med ikoner via `@endwise/ui`. **Ingen magnify, bounce eller scale** ved klikk/hover (F42-05). `GlassDock.css` og `tokens.css` mapper til Endwise/Mobbin: ink `#141414`, muted `#616161`, radius 24px, hairline, ingen glass-skygge. ⛔ `#0066ff`.
