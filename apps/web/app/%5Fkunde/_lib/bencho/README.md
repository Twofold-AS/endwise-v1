# Bencho Magnifying dock

MIT. Kilde: [cabralorenzo/bencho `blocks/dock`](https://github.com/cabralorenzo/bencho/tree/main/blocks/dock). Live: https://bencho.dev/blocks/dock (`?c=dock&theme=light`).
