# Dealer-chrome — Desktop Ronny (lås 2026-09-05)

Dette er **fasit** for Ronny på **desktop** (`md+`). Telefon-sheet er separat og urørt — se `docs/endwise-dealer-chrome-sheet-fasit.md`.

## Åpning

- Avatar rett til venstre for sidebar-toggle i **sidebar-header** (desktop persistent sidebar).
- Ikke midt-logo-toppbar på desktop.

## Flate

- Høyre **overlay-panel** over main content (ikke skyv/push sidebar).
- Lett scrim bak panelet.
- Escape og X lukker.
- Max-bredde **400px**.

## Header

- Midt/venstre: avatar + «Ronny»
- Høyre: X
- **Ingen** forstørr, **ingen** drag-handle.

## Don't

- Ikke bottom sheet på desktop
- Ikke Ronny-stripe/peek
- Ikke midt-modal
- Ikke endre telefon-sheet (80/100, radius 16, midt-logo, etc.)
