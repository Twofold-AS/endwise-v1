Hver linje er én oppgave. Klikk på raden for å se hele beskrivelsen, fase, område og status — og for å endre status. Grupperingen bytter mellom hva (kategori) og når (fase).

Kanonisk status ligger i const ROADMAP i denne fila; kategoriene i const KATEGORIER rett under, og hvert punkt bærer kat (og sub der kategorien har underkategorier). Klikk-endringer er lokale overstyringer (localStorage) til de eksporteres og committes. ID-ene matcher endwise-byggeplan-total.md 1:1.
