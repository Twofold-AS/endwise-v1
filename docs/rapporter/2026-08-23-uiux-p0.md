# Rapport — UI/UX P0 (23.08.2026)

## Hva er gjort

### F1-10 / F5-26 — Invite + 2FA + oppstart = første klikk
- `/invitasjon/[token]` viser 2FA-kode i samme skall (logo + kort) etter passord.
- `twoFactorRedirect` og `TWO_FACTOR_REQUIRED` → `authClient.twoFactor.*`, `loadingText="Bekrefter …"`.
- Fersk invitee sendes aldri til `/signin`. Eksisterende konto (`kreverPassord:false`) gjør det.
- Etter ekte sesjon: `organization.setActive` og `location.assign`. Eier → `/oppstart`. Ansatt → `session.me.landing`.
- `/signin` lander eier uten ferdig onboarding på `/oppstart` via `session.me.landing`.
- `/oppstart`: Visningsnavn · Team. Tillegg bare hvis `optional.length > 0`. Ingen avatar-steg.

### F6-19 — Avatar-velger av
- Fire nedtrekk fjernet. Profil: Avatar 48 + `hover` + «Ny tilfeldig» (humør always happy).
- Ikke i oppstart, ikke på widget/kunde.

### F5-19 — Varslingslyder
- Full-bredde `border-2`-knapp erstattet med settings-rad som `/innstillinger/varsler`: `Switch` fra `@endwise/ui`, track `--ew-accent`. `lyd.test()` ved påslag. Ingen `cuelume.bind()`.

### F5-26 / F5-32 — Pakkevelger
- Tre `radio`-kort i `md:grid-cols-3`. Valgt: `border-fg bg-accent-soft`. Hoydepunkter bare på valgt.
- Én avkrysningsliste: «Tillegg som ikke ligger i {nivå}». Shop og SMS skjult. Kryss = optional for eier.
- Samme `NivaaValg` i «Endre pakke». Endwise-tenant uten resend/slett/«alle huket».

## Hva gikk galt
Alt gikk som planlagt. Ingen blokkeringer. GDPR-slett og invite-chrome/e-post-HTML er urørt.
